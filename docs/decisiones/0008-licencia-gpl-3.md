# 8 · Licencia GPL-3.0

**El problema.** Quiero que cualquier local pueda usar Yedsa gratis y que cualquiera pueda mejorarlo, pero no que alguien lo tome, le cierre el código y lo venda como suyo.

**Lo que decidí.** GPL-3.0. Cualquiera puede usar, estudiar, modificar y compartir Yedsa, incluso en un negocio. Pero si reparte una versión modificada, tiene que entregar su código con la misma licencia y mantener mi nombre.

**Qué implica.**
- Nadie puede hacer una versión cerrada de Yedsa. Las mejoras que se repartan quedan libres para todos.
- Descarté las licencias "no comerciales": prohíben usarlo en un negocio, y un LAN center es un negocio. Además, no cuentan como código abierto.
- Descarté MIT: permite exactamente lo que quiero evitar, que alguien cierre el código.
